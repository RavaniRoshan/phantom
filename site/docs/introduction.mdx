Phantom is a **background computer-use agent for Windows**. You give it a plain-language
task, it works inside an isolated Windows VM, and it reports an outcome you can verify.

## Why it exists

Most desktop agents either drive your own machine (unsafe) or hide a desktop and then
fail to see it (black frames). Phantom's first spike proved both failure modes. The
product is built around the answer: a real interactive VM session, a guest agent inside
it, and a control plane the GUI talks to.

:::note
Phantom is a private beta. Check the [release gates](/docs/benchmarks/release-gates)
before relying on it for real work.
:::

## The three guarantees

1. **Your desktop stays yours.** Desktop actions happen in a separate VM, not your session.
2. **You stay in control.** The app shows every step, asks before consequential actions,
   and lets you take over the VM.
3. **Success is checked.** A model saying `done` is not enough; criteria, artifacts and
   an audit chain decide.
