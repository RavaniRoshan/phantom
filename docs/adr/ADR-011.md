# ADR-011 — Bring-your-own keys, validate-on-save, and free-tier consent

**Status:** Accepted (2026-11-18)
**Work item:** B3 (see `docs/BETA-BUILD-PLAN.md`)
**Context:** users must configure models in the app, and screenshots are sensitive data.

## Context

Provider discovery is uneven: OpenAI's model list has no capability data; Anthropic's and Gemini's do; OpenRouter's includes pricing but uses `-1` as a sentinel (source list in `research/phantom-beta-readiness.md`). Windows Credential Locker caps an app at 20 credentials (source: https://learn.microsoft.com/en-us/windows/apps/develop/security/credential-locker). Gemini's free tier uses submitted content to improve products while its paid tier does not (source: https://ai.google.dev/gemini-api/docs/pricing). OpenRouter `:free` is capped at 20 RPM / 50 RPD until ≥10 credits are purchased (source: https://openrouter.ai/docs/api-reference/limits). GitHub Models was retired on 2026-07-30 (source: https://docs.github.com/en/github-models) and must not be offered.

## Decision

1. One provider record shape for OpenAI, Anthropic, Gemini, OpenRouter and Local/OpenAI-compatible, with per-provider adapters for auth, discovery, capabilities, validation and pricing.
2. Validate keys **on save** with six distinct outcomes (accepted, 401, 403, 429, unreachable, connected-but-no-models). Never leave the user to debug in the chat.
3. Capability precedence: live metadata → shipped static table → "unknown, treated as text-only". Never advertise an unverified vision capability.
4. Store all keys as one DPAPI-encrypted blob under a single Credential Locker entry; mask after save; never write a key to config, logs or a support bundle. Portable mode is explicitly labelled "unencrypted".
5. Extend the gRPC decision request with per-request `provider`, `model` and `key_ref` so switching models in the UI takes effect on the next step.
6. Default free model is Gemini Flash-Lite **only after an explicit in-app consent** explaining free-tier data use; paid Gemini 3.8 Flash is the no-training option; local Qwen3-VL via Ollama is offered for offline use. OpenRouter free and NVIDIA NIM are demo-only fallbacks.
7. Display per-task cost as "estimated at list price"; never show `-1` as free.

## Consequences

- Proto and Python provider changes are required, plus a settings UI and an auditable consent flag.
- Free-tier availability and RPD are volatile; the UI must show the project's actual quota rather than a hard-coded promise.
- Legal review of the privacy policy and provider terms is still required before the public beta.
