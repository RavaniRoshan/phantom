On 2026-11-18, workflow **Windows GUI golden (B4/B6)** ran on GitHub-hosted
`windows-2022` (run `44296179855`, conclusion `success`).

## Evidence

- `cargo build -p phantom-guest` succeeded.
- `scripts/verify-guest-capture.ps1` started the guest agent in the workflow's
  interactive session and fetched `/screenshot`.
- The uploaded artifact `guest-capture.png` is a **1024 × 768 PNG**, 483,034 bytes,
  with **256 distinct byte values** — not black, not blank.
- The same run passed the deterministic golden harness: **20 pass / 0 fail / 40 skipped**.

## Why it matters

The original hidden-desktop approach failed with all-black captures. This run is the
first live proof that the replacement architecture — a guest agent in a real console
session — produces a trustworthy frame.

## Reproduction

```bash
gh workflow run "Windows GUI golden (B4/B6)" --ref main
gh run watch <run-id> --exit-status
gh run download <run-id> --name guest-capture --dir artifacts
```
