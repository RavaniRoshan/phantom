# ADR-012 — Tauri NSIS packaging with free/low-cost signing

**Status:** Accepted (2026-11-18)
**Work item:** B5 (`docs/BETA-BUILD-PLAN.md`)
**Context:** one installer, no terminal, trustworthy updates, minimal budget.

## Context

MSIX gives package identity (toasts, background tasks) and Store distribution, but **Tauri cannot produce MSIX** — its Store route links an external EXE/MSI installer. Self-signed binaries get the same SmartScreen treatment as unsigned; EV certificates no longer receive special SmartScreen reputation (the Microsoft doc gives no year). Azure's managed signing service is now called **Artifact Signing**: Basic $9.99/month (5,000 signatures), Premium $99.99/month, billed from account creation and not prorated; individual Public Trust validation is **US/Canada only** with an Individual Azure billing account matching government ID and 1–30 business days of validation. SignPath Foundation offers free HSM-backed signing to qualifying open-source projects, with manual per-release approval and the publisher identity "SignPath Foundation". Tauri's updater requires signature verification (cannot be disabled).

## Decision

1. Ship a **Tauri v2 NSIS** installer, per-user under `%LOCALAPPDATA%` (no admin), with the embedded WebView2 bootstrapper (~1.8 MB).
2. Bundle the Python sidecar through `externalBin` with the target-triple filename suffix; choose portable CPython / PyInstaller onedir / Nuitka by measured size and AV result in B0.5.
3. Signing order: **SignPath Foundation** (free, if eligible) → **Azure Artifact Signing Basic** ($9.99/month, if eligible) → OV certificate on FIPS 140-2 L2 hardware. Never ship self-signed as a "signed" beta.
4. Updater: generated key pair, `.sig` + `latest.json` published via GitHub Releases, passive install mode, rollback by repointing `latest.json` with a custom `version_comparator`.
5. Add third-party notices (`cargo-deny`), PSF and WebView2 notices, and verify with `signtool verify /pa` plus a clean-VM install. SmartScreen warnings may persist for weeks despite valid signing — document this for beta users.
6. MSIX is a **separate later project**, not a Tauri target; EV certificates are explicitly rejected as wasteful.

## Consequences

- No package identity in the beta: tray/toast behavior must be verified empirically (see ADR-009 corrections).
- If the developer is outside US/Canada and SignPath rejects the project, there is no cheap managed signing path; that is a schedule risk to resolve in B0.4.
- winget distribution is deferred until the installer is AV-clean.
