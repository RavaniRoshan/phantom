Phantom is a **code-complete beta candidate**, not a shipped product. The gates below
are copied from the repository's `docs/benchmarks/release-gates.md`.

## Green

- 92 Rust tests, 61 Python tests, 20/20 deterministic golden tasks.
- Fail-closed action parsing: 0 false `done` across 100 malformed cases.
- 50-case red-team scope test: 0 escapes.
- Authenticated webhook and control plane with replay protection.
- Tamper-evident audit chain and local-by-default screenshot policy.

## Proven in CI

A `windows-2022` GitHub Actions run produced a **1024 × 768 non-black PNG** from
the in-guest agent, with no inbound RDP. See [live capture proof](/docs/benchmarks/github-actions-capture).

## Still blocked

- LLM-driven desktop suite: 12/20 × 3 runs.
- LLM-driven browser suite: 18/20.
- 8-hour / 200-task soak.
- Signed installer build with real signing secrets.
- 5/5 unaided onboarding and security/privacy sign-off.

:::danger
Do not ship until those gates pass. `release-gates.md` is the source of truth.
:::
