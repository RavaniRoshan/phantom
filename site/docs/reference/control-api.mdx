All requests require `Authorization: Bearer <token>` and `X-Phantom-Nonce: <unique>`.
Replayed nonces receive `409`; missing credentials receive `401`.

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/tasks` | Submit a task (`prompt`, `priority`, `dedupe_key`). |
| `GET` | `/tasks` | List tasks. |
| `GET` | `/tasks/:id` | Get one task. |
| `POST` | `/tasks/:id/cancel` | Cancel a task. |
| `POST` | `/approvals/:id` | Approve or reject with reason. |
| `GET` | `/artifacts/:id` | List task artifacts. |
| `GET` | `/events` | Server-sent event stream. |
| `GET/PUT` | `/settings` | Read or replace settings. |
| `GET/PUT` | `/vm/status` | Read or update VM status. |

## Event types

`TaskCreated`, `Step`, `Outcome`, `ApprovalNeeded`, `Error`, `VmStatus`.

## Example

```bash
curl -X POST http://127.0.0.1:4546/tasks \
  -H "Authorization: Bearer $PHANTOM_CONTROL_TOKEN" \
  -H 'X-Phantom-Nonce: 9f1c...' \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"Write a release note in Notepad","priority":1}'
```
