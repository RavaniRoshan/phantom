# Security policy

## Supported versions
- `0.1.x` (private beta) — security fixes only.

## Reporting a vulnerability
Email **security@phantom.local** (replace before public beta) or open a private
security advisory. Please include reproduction steps and the affected version.

We will acknowledge within 3 business days, triage within 10, and keep you
informed until a fix ships. Do not open public issues for unpatched vulnerabilities.

## Disclosure policy (CISA VDP)
Phantom accepts reports for: the Windows app, daemon control plane, webhook,
guest agent, and provider key handling. Out of scope: issues requiring physical
access to the user's machine, and third-party provider vulnerabilities.

The project records an intake log, triages with Coordinated Vulnerability
Disclosure, and (for EU users) follows the CRA exploited-vulnerability reporting
timeline before public disclosure.
